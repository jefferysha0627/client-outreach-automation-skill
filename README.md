# Client Outreach Automation Skill

A Codex skill for responsible public-lead outreach:

- search public small-business contacts,
- export deduped Excel/CSV lead lists,
- create Gmail drafts from templates,
- optionally send approved outreach,
- one-click send existing live Gmail drafts with a live Gmail check.

## Install

Copy or install the skill folder:

```bash
mkdir -p ~/.codex/skills
cp -R skills/client-outreach-automation ~/.codex/skills/
```

Then ask Codex:

```text
Use $client-outreach-automation to install the client-outreach tool into this project.
```

## Important Safety Notes

This repository does not include Gmail credentials, OAuth tokens, private lead lists, histories, logs, or processed reports. Each user must create their own Google OAuth credentials and comply with applicable email, privacy, and unsubscribe rules.
